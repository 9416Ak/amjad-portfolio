# Amjad — Personal Portfolio

A responsive React + Vite portfolio website with a dark editorial visual style.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code / terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing

Update these placeholders in `src/main.jsx`:
- `your.email@example.com` with your real email.
- GitHub and LinkedIn URLs with your profile URLs.
- Project links/statuses with live repositories or demos.
- Add a downloadable resume link if you want one.

## Build for deployment

```bash
npm run build
```

Deploy the generated `dist` folder to Vercel, Netlify, or another static hosting provider.
